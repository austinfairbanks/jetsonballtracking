1. **What is it?** An agent skill that turns a project into a short launch video with music, motion, and share copy, using Hyperframes.

4. **Actual material:** The source hero, documented agent prompt and output filenames, and the repository’s real rendered example videos. Brag has an agent workflow, not a separate graphical editor.
5. **Shortest satisfying video:** The requested 20 seconds supports command → output → proof → CTA.

7. **Audio:** Warm upbeat music with sparse, motion-matched typing and card/reveal accents; no narration.
8. **Share caption:** We used /brag to brag about /brag: one command, a launch video, and the share copy to go with it.
9. **User flow:** Open a project in a coding agent → ask `let's /brag` → receive a video, plan, composition brief, and share copy in `brag-output/`.
